# AWS Academy 지식 점검 – Amazon VPC / 네트워킹

출처: AWS Academy 모듈 지식 점검 (문제 10개)

---

## 1. Amazon Virtual Private Cloud(Amazon VPC)를 사용할 경우 VPC에 구성할 수 있는 가장 작은 크기의 서브넷은 무엇입니까? (가장 적절한 답변 선택)
- /30
- /24
- /26
- **/28** ✅

> 해설: VPC 서브넷 CIDR은 /16 ~ /28 범위로 지정할 수 있습니다. /28은 IP 16개이며, AWS 예약 IP 5개를 빼면 11개를 사용할 수 있습니다.

## 2. Amazon Virtual Private Cloud(Amazon VPC)를 사용할 경우 VPC에 구성할 수 있는 최대 IP 주소 범위는 어떻게 됩니까? (가장 적절한 답변 선택)
- /30
- **/16** ✅
- /28
- /24

> 해설: VPC CIDR 블록은 최대 /16(IP 65,536개), 최소 /28까지 지정할 수 있습니다.

## 3. 프라이빗 서브넷의 리소스가 인터넷에 액세스하도록 허용해야 합니다. 이 액세스를 활성화하려면 다음 중 어느 것이 있어야 합니까? (가장 적절한 답변 선택)
- **NAT 게이트웨이** ✅
- 보안 그룹
- 라우팅 테이블
- 네트워크 액세스 제어 목록

> 해설: NAT 게이트웨이는 퍼블릭 서브넷에 배치합니다. 이를 통해 프라이빗 서브넷의 리소스는 인터넷으로 나가는 연결만 할 수 있고, 외부에서 먼저 들어오는 연결은 차단됩니다.

## 4. 회사에서 어떤 AWS 네트워킹 서비스를 사용하여 AWS 내에 가상 네트워크를 생성할 수 있습니까? (가장 적절한 답변 선택)
- AWS Direct Connect
- AWS Config
- Amazon Route 53
- **Amazon Virtual Private Cloud(Amazon VPC)** ✅

> 해설: Direct Connect는 온프레미스와 AWS를 잇는 전용 회선, Config는 리소스 구성 감사, Route 53은 DNS 서비스입니다.

## 5. 참 또는 거짓? 프라이빗 서브넷은 인터넷에 직접 액세스할 수 있습니다.
- 참
- **거짓** ✅

> 해설: 프라이빗 서브넷의 라우팅 테이블에는 인터넷 게이트웨이로 가는 경로가 없습니다. 그래서 직접 인터넷에 접근할 수 없고, NAT 게이트웨이 같은 중간 경로가 있어야 합니다.

## 6. Amazon CloudFront가 지연 시간이 짧은 전송을 보장하기 위해 사용하는 AWS 글로벌 인프라의 구성 요소는 무엇입니까? (가장 적절한 답변 선택)
- **AWS 엣지 로케이션** ✅
- Amazon Virtual Private Cloud(Amazon VPC)
- AWS 가용 영역
- AWS 리전

> 해설: CloudFront는 전 세계 엣지 로케이션에 콘텐츠를 캐싱해 두고, 사용자와 가장 가까운 곳에서 전송합니다.

## 7. 다음 중 VPC의 서브넷 계층에 적용할 수 있는 선택적 보안 제어는 무엇입니까? (가장 적절한 답변 선택)
- 웹 애플리케이션 방화벽
- **네트워크 ACL** ✅
- 보안 그룹
- 방화벽

> 해설: 네트워크 ACL은 서브넷 단위로 적용되고, 상태 비저장 방식이라 허용/거부 규칙을 모두 둘 수 있습니다. 보안 그룹은 인스턴스(ENI) 단위로 적용되고, 상태 저장 방식이라 허용 규칙만 둡니다.

## 8. Amazon Virtual Private Cloud(Amazon VPC)를 사용하여 새 VPC를 생성하면 어떻게 됩니까? (가장 적절한 답변 선택)
- **기본 라우팅 테이블이 기본적으로 생성됩니다.** ✅
- 인터넷 게이트웨이가 기본적으로 생성됩니다.
- 3개의 서브넷이 각 가용 영역에 대해 하나씩 기본적으로 생성됩니다.
- 하나의 가용 영역에 3개의 서브넷이 기본적으로 생성됩니다.

> 해설: 사용자 지정 VPC를 만들면 기본(main) 라우팅 테이블, 기본 네트워크 ACL, 기본 보안 그룹이 자동으로 생성됩니다. 인터넷 게이트웨이와 서브넷은 직접 만들어야 합니다.

## 9. 다음 중 AWS에 호스팅된 Amazon Elastic Compute Cloud(Amazon EC2) 인스턴스를 보호하는 데 사용할 수 있는 항목은 무엇입니까? (가장 적절한 답변 선택)
- AMI
- 위 항목 모두 해당
- **보안 그룹** ✅
- 인터넷 게이트웨이

> 해설: 보안 그룹은 인스턴스의 인바운드/아웃바운드 트래픽을 제어하는 가상 방화벽입니다. AMI는 인스턴스용 이미지이고, 인터넷 게이트웨이는 인터넷 연결용이라 둘 다 보호 수단이 아닙니다.

## 10. 당신은 기존 인프라를 AWS로 마이그레이션하는 대규모 리테일 기업에 근무하는 Solutions Architect입니다. 그리고 사용자 지정 VPC를 사용하기를 권장했습니다. VPC를 생성할 때 VPC를 10.0.1.0/24의 IPv4 Classless Inter-Domain Routing(CIDR) 블록(총 256개의 IP 주소)에 할당합니다. 사용할 수 있는 IP 주소는 몇 개입니까? (가장 적절한 답변 선택)
- 246
- 256
- **251** ✅
- 250

> 해설: AWS는 각 서브넷에서 IP 5개를 예약하므로 256 − 5 = 251개를 사용할 수 있습니다.
> - .0: 네트워크 주소
> - .1: VPC 라우터
> - .2: DNS
> - .3: 향후 사용 예약
> - .255: 브로드캐스트
